
# My Todo List

A simple and responsive Todo List application built using React. This project helps users manage their daily tasks efficiently by adding, editing, and deleting tasks.

## 🚀 Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🎨 Clean and responsive UI
- ⚡ Fast performance with React

## Technologies

- React (JSX)
- JavaScript 
- HTML5
- CSS3
- Vite

## Installation Process

Go to project folder:

cd todo-jsx

## Install dependencies:

npm install

## Run the project:

npm run dev
